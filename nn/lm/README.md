# Ядро 5 — модель и проверки

Одна формула вместо каскада слоёв (сеть → щит → словари → n-граммы …). На каждое слово —
два прочтения одних клавиш; для каждого языка стоимость −ln P складывается из:

- частоты слова (`nn/ngram/qsngram.bin`) + символьной модели «как выглядит слово языка»
  (`qschar.bin`) + модели опечаток (одна правка от известного слова);
- пары с предыдущим словом того же языка;
- регистра (слово целиком заглавными: UI, IP, РФ);
- перехода: смена языка между соседними словами редка (π = 0.04), в начале ввода —
  ожидание приложения (терминал/код → английский, чат → русский, дальше — по тому,
  что человек реально оставляет на экране в этом приложении);
- надбавки за «язык не совпадает с раскладкой».
- **личного слоя** (если включён): частоты слов — смесь корпуса и своих
  (`(1−γ)·P_корпус + γ·P_личн`, γ = 0.3), пара с предыдущим словом — и своя тоже
  (любого языка: «сервер HA»; за смену языка второй раз не платим), привычная опечатка
  («шына» → «шина») — как слово своего языка чуть дороже (+ln 2). Доводом слово или пара
  становится с веса 2: принятое слово +1, исправление +3.

LO = стоимость(набранное) − стоимость(другое); свап при LO > θ и если другое прочтение —
слово. Короткое неуверенное слово откладывается и исправляется задним числом по
следующему. Вето нет — любое решение раскладывается в лог по слагаемым.

| файл | что |
|---|---|
| `model.py` | эталон ядра (Python); Swift `Core5.swift` и C# `Core5.cs` — порты один в один |
| `charlm.py` | обучение и чтение символьной модели (QSCL1) |
| `qschar.bin` | символьная модель RU+EN, порядок 5, + таблица регистра |
| `core5-selftest.json` | эталон паритета: те же входы → те же решения в Swift/C# (и с личным слоем) |
| `make_selftest.py` | собирает эталон (только открытые тестовые фразы) |
| `parse_log.py`, `eval_log.py` | прогон реального лога приложения через ядро |
| `eval_phrases.py` | прогон наборов фраз (`nn/sem/*.txt`) |
| `count_words.py`, `count_caps.py` | частоты слов и регистра из корпуса для обучения |

## Обучение

```
python3 nn/sem/fetch_corpus.py                 # корпус (если нет)
python3 nn/ngram/build.py                      # qsngram.bin — частоты слов и пар
python3 nn/lm/count_words.py                   # data/words-{ru,en}.tsv
python3 nn/lm/count_caps.py wiki-ru 3000000    # data/caps-*.tsv (по каждому источнику)
python3 nn/lm/charlm.py train --order 5 --prune 1,1,1,2,2 --out nn/lm/qschar.bin
python3 nn/lm/make_selftest.py                 # после любого изменения модели или model.py
```

## Проверки

```
# паритет порта с эталоном
QSwitcher.app/Contents/MacOS/QSwitcher --selftest-core     # мак
#   винда — строка «Ядро 5 / самопроверка» в %APPDATA%\QSwitcher\qswitcher.log

# реальный лог (результат — личный, только в nn/lm/data/)
python3 nn/lm/parse_log.py ~/Library/Logs/QSwitcher.log nn/lm/data/events.json
python3 nn/lm/eval_log.py nn/lm/data/events.json --char nn/lm/qschar.bin --ngram nn/ngram/qsngram.bin

# наборы фраз
python3 nn/lm/eval_phrases.py nn/sem/scan-phrases.txt --char nn/lm/qschar.bin --ngram nn/ngram/qsngram.bin --right
```

## Результаты (сентябрь 2026)

Реальный лог за месяц (2 435 слов, спорные размечены вручную):

| | ошибок | ложных свапов | пропусков | ошибок на первом слове |
|---|---|---|---|---|
| прежнее ядро (wave48–49) | 60 (2.51%) | 13 | 47 | 22 |
| ядро 5 | 17 (0.71%) | 0 | 17 | 3 |

Слова от 4 букв: 12 ошибок → 0.

Коллизии (`scan-phrases.txt`, 2 720 строк, оба прочтения — слова): 80% → 83.3%.
Оставшиеся пропуски — 1–2-буквенные личные сокращения (ГШ, ыр, чл…); их закрывают
профиль (обучение с контекстом) и правила.

Личный слой на том же логе (`eval_log.py --personal --warm`: месяц в режиме «обучение»,
потом прогон): 17 ошибок → **9 (0.38%)**, ложных свапов по-прежнему 0. Без прогрева
(`--personal`) — те же 17: в логе почти все пропуски — первое появление личного
сокращения (awg, mtp, ГШ), а выучить можно только со второго.

## Настройки (config.json)

| мак | винда | по умолчанию | |
|---|---|---|---|
| `core` | `Core` | `v5` | `legacy` — прежний каскад |
| `coreTheta` | `CoreTheta` | 2.0 | порог свапа (наты) |
| `corePi` | `CorePi` | 0.04 | вероятность смены языка между словами |
| `coreLayoutBias` | `CoreLayoutBias` | 1.0 | надбавка «язык ≠ раскладка» |
| `coreDeferShort` | `CoreDeferShort` | true | короткие — задним числом по соседу |
| `personalMode` | `PersonalMode` | `on` | личный слой: `on` работа + обучение, `learn` только обучение, `frozen` только работа, `off` |
