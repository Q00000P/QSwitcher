# Семантический слой QSwitcher (v2)

Буквенная сеть (`nn/qsnet.bin`) решает «русское слово набрано не в той раскладке»
по буквам. Она не знает тем, поэтому коллизии (`HA/РФ`, `ут/EN`, `ha/рф`,
`vs/мы`) ей не по силам. Этот слой добавляет смысл.

## Три слоя данных
| слой | где | что |
|---|---|---|
| база | в приложении, обновляется релизами | `qsvec.bin` — векторы слов RU+EN в одном пространстве, ~10–15 МБ |
| профиль | у пользователя, **синкается** | темы-навыки (именованные центроиды), личные векторы терминов, исправления с темой окна, правила |
| состояние окна | в памяти | тема беседы — затухающее среднее векторов последних ~40 принятых слов в этом приложении |

## Решение коллизии
У клавиш `ha` два чтения — `HA` и `РФ`. У каждого чтения в профиле — центроид тем,
в которых пользователь его выбирал. Тема окна ближе к какому центроиду — то и
ставим (косинус; разница меньше порога — как набрано). Прототипы, не градиент:
работает с двух примеров, объяснимо в логе («тема ближе к HA на 0.31»),
переносится синком профиля целиком.

## Пайплайн (мак)
```bash
python3 -m pip install --user gensim
python3 nn/sem/fetch_corpus.py --telegram ~/Downloads/Telegram\ Desktop/ChatExport/result.json
python3 nn/sem/train_vectors.py
python3 nn/sem/qsvec.py nn/sem/qsvec.bin near сервер
python3 nn/sem/qsvec.py nn/sem/qsvec.bin topic "я настроил сервера и датчики в конфиге" ha рф
```
`fetch_corpus.py` качает OpenSubtitles и Wikipedia (OPUS, моно ru/en, ≈3–4 ГБ) и
Tatoeba с переводами; пары переводов кладутся в одну строку — так пространства
RU и EN выравниваются. `--telegram` / `--extra` — личные тексты, идут с весом.
Обучение: gensim FastText skip-gram, dim 64, n-граммы 3..5, ~1–2 ч на M5.

## Профиль (`profile.py`, эталон для портов)

`profile.json` — второй слой, тот, что синкается. Хранит **чтения коллизий**:
у клавиш `ha` есть варианты `HA` и `РФ`, у каждого — центроид тем окна, центроид
левых соседей, статистика регистра, счётчик и время. Сырые фразы не хранятся:
только векторы, поэтому файл маленький и приватный.

Решение: `1.0·cos(левый сосед) + 0.6·cos(тема) + 0.4·регистр`; выигрывает лучшее
чтение, но только если отрыв от второго больше `MARGIN` — иначе оставляем как
набрано и молчим. Сила регистра берётся из статистики пользователя: пишет `РФ`
всегда капсом — сигнал сильный; пишет вперемешку — сигнала нет.

Синк — `Profile.merge`: центроиды складываются с весами `count`, счётчики
регистра суммируются, время — максимум. Порядок слияния не важен, конфликтов нет.

```bash
python3 nn/sem/profile.py nn/sem/qsvec.bin observe ha HA "мой сервер настроил конфиг"
python3 nn/sem/profile.py nn/sem/qsvec.bin observe ha РФ "живу в стране"
python3 nn/sem/profile.py nn/sem/qsvec.bin decide  ha рф "настроил сервер"
python3 nn/sem/profile.py nn/sem/qsvec.bin show
```

## Формат qsvec.bin (QSV1)
См. docstring `train_vectors.py`. Эталонный лукап — `qsvec.py` (`QSVec.vector`,
`topic`, `ft_hash`, `ngrams`); паритет с gensim по OOV-словам проверен (cos 1.000).
