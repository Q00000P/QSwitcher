# QSwitcher

Автопереключатель раскладки RU↔EN для macOS. Исправляет текст, набранный
не в той раскладке, и переключает раскладку когда это оправдано.

Windows-версия — в папке [windows](windows/).

Универсальный бинарь (Intel + ARM), минимум macOS 11. Внешних зависимостей нет —
только системные фреймворки.

## Сборка с нуля

```bash
cd ~/Downloads
tar -xzf QSwitcher-source.tar.gz
cd QSwitcher
chmod +x *.sh

./fetch-dicts.sh
./make-icon.sh
./make-cert.sh

./make-app.sh
cp -R QSwitcher.app /Applications/
rm -rf QSwitcher.app
open /Applications/QSwitcher.app
```

`fetch-dicts.sh` качает словари (~50 МБ), они не хранятся в репозитории.
`make-icon.sh` и `make-cert.sh` запускаются по одному разу.

После запуска выдать права: Системные настройки → Конфиденциальность и
безопасность → Универсальный доступ → добавить QSwitcher. Приложение подхватит
их само в течение пары секунд, перезапускать не нужно.

## Пересборка после правок

```bash
cd ~/Downloads/QSwitcher
killall QSwitcher 2>/dev/null
rm -rf .build /Applications/QSwitcher.app QSwitcher.app
swift build -c release
./make-app.sh
cp -R QSwitcher.app /Applications/
rm -rf QSwitcher.app
open /Applications/QSwitcher.app
```

`rm -rf .build` обязателен — иначе может собраться старый код.

## Подпись

`make-cert.sh` создаёт самоподписанный сертификат на 10 лет. Без него сборка
подписывается ad-hoc, и тогда **права Accessibility слетают при каждой
пересборке**: ad-hoc идентичность привязана к хешу бинаря, а он меняется
каждый раз, и система считает приложение новым.

Если скрипт не сработает, то же самое делается через интерфейс:
Связка ключей → Certificate Assistant → Create a Certificate,
имя `QSwitcher Self-Signed`, тип Self Signed Root, назначение Code Signing,
срок 3650 дней. Потом двойной клик по сертификату → Trust →
Code Signing: Always Trust.

Для распространения это ничего не даёт — Gatekeeper самоподпись не знает так же,
как и ad-hoc. Помогает только локально.

## Перенос на другой Mac

```bash
./make-dmg.sh
```

На целевой машине снять карантин:

```bash
xattr -dr com.apple.quarantine /Applications/QSwitcher.app
```

Карантин вешается на всё скачанное браузером. Через `git clone`, `curl` или
флешку с exFAT его не будет.

## Горячие клавиши

| | |
|---|---|
| **правый Option** | свапнуть набранное слово, повторно — вернуть обратно |
| **левый Option** | свапнуть выделенный мышью текст |
| **⇧ + правый Option** | свапнуть **и запомнить** решение для этого слова |
| **⌘⇧Space** | универсально: выделение если есть, иначе буфер |
| **Esc** | отменить последнее автопереключение (10 секунд) |
| **⌃⇧U** | циклическая смена регистра выделенного |
| **⌃⇧T** | транслит выделенного (ГОСТ 7.79-2000) |

## Самообучение

Для коротких слов однозначного ответа не существует: `вк` — это ВКонтакте или
промах вместо `dr`? Зависит от того, чем человек занимается. Поэтому решает
пользователь, а программа запоминает.

**⇧ + правый Option** — единственный способ создать правило. Свапнул с Shift —
впредь будет свапаться само. Повторил в обратную сторону — правило снято.
Обычный свап и тоггл ничего не запоминают, так что оба варианта можно
спокойно смотреть.

Меню → «Выученные правила…» показывает списки, «Сбросить выученное…» очищает.

### Личный слой

Ядро подстраивается под то, как пишешь именно ты: запоминает слова, которые ты
оставляешь на экране (засчитываются на следующем пробеле, если слово не тронул),
пары соседних слов (и через смену языка: «сервер HA»), свои опечатки (набрал,
стёр часть, исправил) и ошибки свитчера: тоггл назад, ручной свап, «стёр и набрал
в другой раскладке» — с тройным весом, так что одного исправления хватает. Твои
сокращения (`awg`, `mtp`, `гпт`) после первой правки решаются правильно. Поля
паролей, исключённые приложения и формулы не учатся.

Меню → «Личный слой»: **Выключен** · **Обучение** (только наблюдает, в решениях не
участвует) · **Работа + обучение** (по умолчанию) · **Только работа** (больше не
учится). Там же сводка и «Очистить…». Хранится зашифрованным (ключ в Keychain).

«Экспорт навыков в файл…» / «Импорт навыков из файла…» — всё выученное одним файлом:
правила, стоп- и форс-слова, исключения и английский ввод, ожидание языка по
приложениям, личный слой, журнал профиля. С паролем (`.qsskills`, AES-256-GCM) или
открытым JSON. Формат общий с виндой; импорт сливает, ничего не стирая. Этот же файл
станет основой синхронизации между устройствами.

## Как принимаются решения

С версии 5 (мак wave50, винда wave15) решает **ядро 5** — одна формула вместо
каскада правил. Одни и те же клавиши читаются двумя способами, и для каждого
считается правдоподобие: частота слова, «похоже ли оно на слово этого языка»
(символьная модель — ловит опечатки, сленг, новые слова), пара с предыдущим
словом, регистр (аббревиатуры), редкость смены языка между соседними словами и
ожидание языка в этом приложении. Свап — когда другое прочтение заметно
правдоподобнее и само является словом. Короткое неуверенное слово («yt»)
решается по следующему и исправляется задним числом. Подробно, с цифрами и
командами проверки: [`nn/lm/README.md`](nn/lm/README.md).

Личный слой добавляется в ту же формулу: частоты слов — смесь корпуса и твоих, пары —
и твои тоже, привычные опечатки читаются как слова своего языка.

Сверху остаются решения человека: стоп- и форс-слова, выученные правила,
обученный профиль (HA/РФ), поле пароля и приложения из списка «английский ввод».
Прежний каскад включается ключом `"core": "legacy"` в config.json.

Раскладка переключается только после двух подряд конвертаций в одну сторону.
Разовая вставка (`NL` посреди русского текста) текст исправит, но раскладку
не тронет — и дальше можно писать по-русски как ни в чём не бывало.

## Данные

```
~/Library/Application Support/QSwitcher/config.json     настройки
~/Library/Application Support/QSwitcher/learned.json    выученные правила
~/Library/Application Support/QSwitcher/personal.qsp    личный слой (зашифрован)
~/Library/Application Support/QSwitcher/app-lang.json   ожидание языка по приложениям
~/Library/Application Support/QSwitcher/dicts/          пользовательские словари
~/Library/Logs/QSwitcher.log                            открытый лог
~/Library/Logs/QSwitcher/securelog.db                   защищённый лог
```

Конфиг перечитывается каждые 2 секунды. Пользовательские словари `ru.txt`
и `en.txt` подмешиваются к основным при старте.

Заметные настройки: `excludedApps` — где не работать (по активному приложению
или по владельцу фокуса), `stopWords` и `forceWords` — ручные исключения,
`switchLayoutAfter` — через сколько конвертаций менять раскладку (0 — никогда),
`soundConvertOnly` и `soundConvertAndSwitch` — разные звуки для «исправил» и
«исправил и переключил».

## Защищённый лог

Пишется в зашифрованную базу (AES-GCM, ключ в Keychain). Открывается через меню
с подтверждением Touch ID. Обычный лог при этом остаётся открытым текстом —
защищённый нужен для истории набора, которая по сути чувствительна.

## Ограничения

**Spotlight и поиск программ.** Эти поля не принимают синтетический backspace,
поэтому заменить в них текст невозможно: старый символ остаётся, новый
дописывается рядом. Добавь `com.apple.Spotlight` в `excludedApps`, чтобы
программа их не трогала.

**Electron-приложения** (Telegram, VS Code, Claude) не отдают выделенный текст
через Accessibility. Для них используется запасной путь через буфер обмена —
работает, но медленнее.
