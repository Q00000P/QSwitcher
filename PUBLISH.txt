ПУБЛИКАЦИЯ QSwitcher НА GITHUB + HOMEBREW TAP
═══════════════════════════════════════════════════════════

Два репозитория:
  1. Q00000P/QSwitcher          — сам проект (исходники + релизы)
  2. Q00000P/homebrew-tap          — tap с cask-формулой

───────────────────────────────────────────────────────────
ЧАСТЬ 1: Репозиторий проекта
───────────────────────────────────────────────────────────

# 1. Создай репо на GitHub: Q00000P/QSwitcher
#    (приватный или публичный — см. примечание внизу)

# 2. Инициализируй гит локально
cd ~/Downloads/QSwitcher
git init
git add .gitignore *.swift *.sh *.md Package.swift Sources/QSwitcher/*.swift
git add Sources/QSwitcher/Resources/*.json   # n-граммы и layout (не txt-словари!)
git add autoswitcher-cask.rb
git commit -m "QSwitcher 0.7"
git branch -M main
git remote add origin https://github.com/Q00000P/QSwitcher.git
git push -u origin main

# Словари ru.txt/en.txt НЕ коммитятся (.gitignore) — они качаются fetch-dicts.sh

───────────────────────────────────────────────────────────
ЧАСТЬ 2: Релиз с .zip
───────────────────────────────────────────────────────────

# 1. Собери релизный zip
cd ~/Downloads/QSwitcher
chmod +x make-release.sh
./make-release.sh

#    Выведет SHA256 — ЗАПОМНИ его, нужен для cask.

# 2. Создай релиз на GitHub:
#    https://github.com/Q00000P/QSwitcher/releases/new
#    - Tag: v0.7
#    - Title: QSwitcher 0.7
#    - Прикрепи файл QSwitcher-0.7.zip
#    - Publish release

───────────────────────────────────────────────────────────
ЧАСТЬ 3: Homebrew tap
───────────────────────────────────────────────────────────

# 1. Создай репо: Q00000P/homebrew-tap
#    ВАЖНО: имя должно начинаться с "homebrew-"

# 2. Локально
mkdir -p ~/homebrew-tap/Casks
cd ~/homebrew-tap

# 3. Скопируй cask-формулу, подставив version и sha256
cp ~/Downloads/QSwitcher/autoswitcher-cask.rb Casks/autoswitcher.rb
#    Открой Casks/autoswitcher.rb и замени:
#      sha256 "ЗАМЕНИ..." → твой SHA из make-release.sh

# 4. Запушь
git init
git add Casks/autoswitcher.rb
git commit -m "Add QSwitcher cask"
git branch -M main
git remote add origin https://github.com/Q00000P/homebrew-tap.git
git push -u origin main

───────────────────────────────────────────────────────────
ЧАСТЬ 4: Установка (на любом маке)
───────────────────────────────────────────────────────────

brew tap Q00000P/tap
brew install --cask autoswitcher

# Обновление потом:
brew upgrade --cask autoswitcher

───────────────────────────────────────────────────────────
ОБНОВЛЕНИЕ ВЕРСИИ В БУДУЩЕМ
───────────────────────────────────────────────────────────

1. Поднять версию в make-app.sh (static let version = "0.8")
2. ./make-release.sh → новый zip + sha256
3. Создать релиз v0.8 на GitHub, прикрепить zip
4. В homebrew-tap обновить Casks/autoswitcher.rb: version + sha256
5. git commit + push
6. У пользователей: brew upgrade --cask autoswitcher

───────────────────────────────────────────────────────────
ПРИВАТНЫЙ vs ПУБЛИЧНЫЙ
───────────────────────────────────────────────────────────

ПУБЛИЧНЫЙ (рекомендую для простоты):
  - tap и релизы открыты
  - любой ставит командой выше без авторизации
  - никто не "узнает" сам по себе — brew не анонсирует
  - найдут только если дашь ссылку

ПРИВАТНЫЙ (только для себя/доверенных):
  - оба репо приватные
  - при установке нужна гит-авторизация (gh auth или токен)
  - cask url на приватный release требует токен — сложнее
  - проще: приватный tap + ПУБЛИЧНЫЙ репо с релизами
    (формула приватная, а .zip скачивается свободно)
