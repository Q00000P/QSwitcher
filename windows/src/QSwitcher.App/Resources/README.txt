ru.txt и en.txt (полные словари, ~50 МБ) скачать так же как на маке:
  curl -L -o ru.txt https://raw.githubusercontent.com/danakt/russian-words/master/russian.txt
  (перекодировать в UTF-8 если нужно: iconv -f cp1251 -t utf-8)
  curl -L -o en.txt https://raw.githubusercontent.com/dwyl/english-words/master/words_alpha.txt
