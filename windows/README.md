# QSwitcher для Windows

Автопереключатель раскладки RU↔EN. Порт macOS-версии: ядро детектора общее,
платформенный слой свой.

Портативный: один exe, рантайм внутри, установка не нужна. Windows 10 1607+
и Windows 11, x64.

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
cd qswitcher-win
dotnet publish src\QSwitcher.App -c Release
```

Готовое приложение:
`src\QSwitcher.App\bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\`

Перед первой сборкой нужны словари — они не хранятся в репозитории (35 МБ):

```powershell
cd src\QSwitcher.App\Resources
curl.exe -L -o en.txt https://raw.githubusercontent.com/dwyl/english-words/master/words_alpha.txt
curl.exe -L -o russian-raw.txt https://raw.githubusercontent.com/danakt/russian-words/master/russian.txt
$src = [System.IO.File]::ReadAllText("$PWD\russian-raw.txt", [System.Text.Encoding]::GetEncoding(1251))
[System.IO.File]::WriteAllText("$PWD\ru.txt", $src, (New-Object System.Text.UTF8Encoding $false))
del russian-raw.txt
```

Русский словарь в cp1251, перекодировка обязательна.

## Перенос на другую машину

Копировать **всю папку publish**, а не только exe: рядом лежит `Resources`
со словарями и звуками. SDK на целевой машине не нужен.

## Горячие клавиши

Приём «тап по модификатору» — нажать и отпустить, не задев других клавиш.
Рука не покидает основную позицию, в отличие от Pause, до которого тянуться
через всю клавиатуру.

| | |
|---|---|
| **тап правый Ctrl** | есть выделение — свапнуть его; нет — слово, повтор — вернуть обратно |
| **⇧ + тап правый Ctrl** | свапнуть **и запомнить** решение (набранное или выделенное одно слово) |
| **тап левый Ctrl** | свапнуть выделенный мышью текст (и там, где UIA его не отдаёт) |
| **правый Ctrl + U** | регистр выделенного |
| **правый Ctrl + T** | транслит выделенного (ГОСТ 7.79-2000) |
| **правый Ctrl + P** | пауза свитчера |
| **Pause** | запасной свап слова (как у Punto Switcher) |

Переназначаются через меню трея → «Горячие клавиши…». Правый Alt намеренно
не занят — это AltGr, он понадобится при добавлении немецкой и испанской
раскладок.

## Самообучение

Для коротких слов однозначного ответа нет: `вк` — это ВКонтакте или промах
вместо `dr`? Зависит от того, чем человек занимается. Поэтому решает
пользователь, а программа запоминает.

**⇧ + тап правый Ctrl** — единственный способ создать правило. Обычный свап
и тоггл ничего не запоминают, так что оба варианта можно спокойно смотреть.

Меню → «Выученные правила…» — список с правкой и удалением поштучно.

## Как принимаются решения

Слово проверяется по словарю текущего алфавита и по словарю противоположного
после свапа. Выбранная раскладка почти не участвует — важно содержимое.

Для слов из 2–3 букв полный словарь бесполезен: в нём 437 двухбуквенных
«слов» вроде `ут`, и почти половина конфликтует с английскими по раскладке.
Для них используются частотные списки (OpenSubtitles).

Раскладка переключается только после двух конвертаций подряд в одну сторону.
Разовая вставка (`NL` посреди русского текста) текст исправит, но раскладку
не тронет.

## Данные

```
%APPDATA%\QSwitcher\config.json     настройки
%APPDATA%\QSwitcher\learned.json    выученные правила
%APPDATA%\QSwitcher\dicts\          пользовательские словари
%APPDATA%\QSwitcher\qswitcher.log   открытый лог
%APPDATA%\QSwitcher\securelog.bin   зашифрованная история набора
%APPDATA%\QSwitcher\securelog.key   ключ, защищённый DPAPI
```

Заметные настройки: `ExcludedProcesses` — где не работать, `StopWords`
и `ForceWords` — ручные исключения, `SwitchLayoutAfter` — через сколько
конвертаций менять раскладку (0 — никогда), `RetroMaxChain` — глубина
ретроконверсии, `ReplaceStartDelayMs` — пауза перед стиранием
(увеличить, если текст иногда уезжает).

## Защищённая история набора

Обычный лог пишется открытым текстом — там границы слов и решения детектора.
Но история набора по природе чувствительна, поэтому идёт в отдельный
зашифрованный файл: AES-256-GCM, каждая запись со своим nonce, ключ защищён
DPAPI и привязан к учётной записи Windows. На другой машине файл
не расшифруется.

На чтение спрашивается Windows Hello. Если его нет, спрашивается обычное
подтверждение — защиту файла это не ослабляет.

Отключается через `SecureLogEnabled` в конфиге. Меню → «История набора…»
показывает и позволяет стереть.

## Звуки

Три разных сигнала, чтобы на слух отличать что произошло: замена без смены
раскладки, замена со сменой, откат. Меняются в конфиге, можно указать имя
файла из `Resources` или полный путь к своему `.wav`.

## Движок 4.0 — «хук как замок»

Замена набранного делается **прямо из низкоуровневого хука**, пока его
callback не вернулся. Пока он не вернулся, система не отдаёт никому следующие
события ввода — они стоят в очереди за ним. Поэтому: клавиша-граница
(пробел/Enter/Tab) съедается, а батч «backspace'ы + текст + граница» уходит
одним `SendInput` до возврата из callback'а. Всё, что нажато после, физически
позади батча — вклиниться некуда. В движке нет ни пауз, ни гейта, ни флага
«идёт замена»: гонка с собственным вводом устранена порядком очереди, а не
таймингами.

Что из-за этого ушло из хука: имя процесса (для исключений) и поле пароля
(для защищённого лога) узнаются заранее — по событиям смены фокуса
(`ForegroundTracker`); звук, лог и правила пишутся через очереди.

Сторож: Windows снимает LL-хук молча, если поток не ответил за 300 мс
(например, полная сборка мусора). Секундный таймер в потоке хука замечает
замирание и переустанавливает хук; медленные callback'и пишутся в лог
(`[hook] медленный callback`).

Выделение (левый Ctrl / регистр / транслит): чтение через UI Automation
(аналог AX на маке), фолбэк — Ctrl+C с проверкой номера последовательности
буфера обмена; вывод — **набором поверх выделения**, без Ctrl+V. Исходный
буфер возвращается сразу после чтения, гонки с вставкой нет.

Откат на прежний движок (очередь → пауза → батч → гейт): в `config.json`
`"Engine": "legacy"` и перезапуск.

## Ограничения

**Меню трея перехватывает клавиатуру.** Пока открыто контекстное меню,
глобальные хоткеи других программ не работают — так устроен WinForms.

**Некоторые поля не принимают синтетический ввод.** В отдельных приложениях
замена может не сработать: старый текст останется, новый допишется рядом.
Такие процессы стоит внести в `ExcludedProcesses`.

## Устройство

```
src/QSwitcher.Core/     платформо-независимое ядро
  LayoutPair.cs         таблицы раскладок, заготовка под другие языки
  Detector.cs           правила принятия решений
  Storage.cs            словари и выученные правила
src/QSwitcher.App/      Windows-слой
  KeyboardMonitor.cs    перехват клавиатуры, буфер слова, решение и батч из хука
  Foreground.cs         фокус по событиям, UIA-чтение выделения, журнал ввода
  KeyMap.cs             свой перевод клавиш без системных вызовов
  TextReplacer.cs       отправка замен, работа с выделением
  Hotkeys.cs            тапы по модификаторам и сочетания
  SecureLog.cs          зашифрованная история
```

Ядро отделено намеренно: детектор выстрадан на macOS десятками итераций,
и переписывать его второй раз смысла не было.

утилиты. Обработка идёт локально, никуда ничего не отправляется.
